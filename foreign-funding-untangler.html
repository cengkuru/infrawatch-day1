Is this railway foreign-funded?

It sounds like a question with one answer. Commit to yours, then watch five countries disagree.

the project, in full

project  a national railway
financing  a sovereign loan (the state borrows, the state repays)
foreign ownership stake  none
repayment  public debt

Public debt means the public pays. Every citizen helps repay this loan through the national budget, whether or not the railway ever reaches their town. So whether it gets counted as foreign-funded is not a filing detail. It decides whether anyone can hold someone to account for it.

the machine

One project. Five rulebooks.

On paper, the railway and its loan are identical everywhere. Nothing about the project changes as it crosses a border. What changes is the test each country applies to decide if it counts as foreign-funded. Drop the same project through all five and watch the stamps disagree.

Ghana · the test that misses it

The ownership test lets it slip.

the reveal

The project did not change. The definition did.

Same loan. Same railway. Same facts. Run it through the gates and the stamps come back different: caught here, slipped there, three still being written. "Foreign-funded" turned out not to be a fact about the project at all. It was a decision, made differently by each rulebook.

the fix

One shared definition every country maps up to.

The answer is not to rewrite five countries' laws. It is one shared, OC4IDS-anchored definition of foreign-funded infrastructure that each country maps its own records up to. Keep the national tests; add one common layer above them, so the same railway finally counts the same way everywhere, and cross-country comparison can be trusted.

CT

The risk the CIPE leads named at the close was keeping this simple and untangled, and making it stick beyond the conference room. A shared definition is how it sticks. Cathy Tai, Director, China in the World, CIPE · plenary close, Day 1

The Day 1 finding, in one breath

"Foreign-funded" is not a fact about a project. It is a decision each country's law makes differently.

Until there is one shared definition to map up to, the same railway is counted in one country and invisible in the next, and no cross-country comparison can be trusted.
