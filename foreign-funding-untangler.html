One instrument, five jurisdictions.

A sovereign loan that builds a railway is the same financing instrument in every country. On paper, nothing about it changes as it crosses a border. What changes is how each country's law decides to count it. Travel east and watch.

Kenya

Caught · counts as foreign-funded

Kenya captures the loan through its public-debt register, so the railway shows up as foreign-funded. Here, the net catches it.

Ghana

Captured mainly on an ownership stake.

Slips through · not counted the same way

Fly west to Ghana and the same project changes status. Ghana captures foreign funding mainly when a foreign entity holds an ownership stake. A sovereign loan without that stake can slip through. Same railway, now invisible.

Nigeria, Ethiopia, DR Congo

Each draws the line somewhere else again.

Move across the rest of the map and the line keeps shifting. Each country's law puts it in a different place, so the same project appears in some registers and vanishes from others, with no harmonised view across them.

the fix

One shared definition every country maps up to.

The answer is not to rewrite five countries' laws. It is one shared, OC4IDS-anchored definition of foreign-funded infrastructure that each country can map its own records up to, so the same railway counts the same way everywhere.

The Day 1 finding, in one breath

"Foreign-funded" is not a fact about a project. It is a decision each country's law makes differently. Until there is one shared definition to map up to, the same railway is counted in one country and invisible in the next, and no cross-country comparison can be trusted.
