The Project Publication Test

A practical method for checking whether a public infrastructure project can be seen, judged, and acted on.

See it. Test it. Voice it.

Publication does not make a project good. It makes its value testable, and gives the public standing to challenge the terms.

Run the test on a project → Open the evidence

 

Start with one infrastructure project. The test shows what is visible, what cannot yet be judged, and what needs to be published next.
