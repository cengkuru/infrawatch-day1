Lifecycle and due date · when should this record exist?

A record is only missing once the project has passed the stage that produces it

Every project moves through six phases, and each phase generates its own records. Before scoring any data point, place the project on this timeline: a record can be absent because it is not yet due, because it does not apply, or because it is due and unpublished. Only the last is ever a zero.

The most damaging confusion in the assessment: scoring a not-yet-due document as a zero. A project under construction cannot have a completion report; its absence is not a disclosure failure. Record it not yet due, and it leaves the calculation until the phase that produces it arrives.

The six phases, and the records each one produces

Broad record types per phase, not the full list; the 40 data points map each point to the project's life.

1 · PreparationNeeds assessment, feasibility and appraisal studies, environmental approvals, budget provision.
2 · ProcurementTender notices, procurement method, bid documents, award decision.
3 · Contract & financial closeThe signed contract, financing agreements, guarantees, the project company's structure.
4 · ConstructionProgress reports, variations and renegotiations, cost and time changes, supervision reports.
5 · OperationTariffs and payments, performance against standards, penalties, service reports.
6 · CompletionCompletion report, final cost, handover records, audits and evaluations.

What placing the project on the timeline changes

Stage decides the question set before search decides the score. For each data point: if the project has not reached the phase that produces the record, mark it not yet due, no search required, no score. If it has, run the sufficient search and score what you find. The project's stage is one of the six things the database retains, and points marked not yet due return to the assessment when the phase arrives.
