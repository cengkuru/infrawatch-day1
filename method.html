The method · a procedure you can run

First you see it, then you test it, then the public can voice it.

Three moves to read any foreign-funded project. Each is a step you can run: a question, the input it needs, the decision it makes, and the output it produces.

Move 1 · See itfrom Day 1

See it

Question
What is being funded, and by whom?
Input needed
Project name, funder, and the CoST IDS basic data points
Decision made
Classify the financing type: sovereign loan, equity, PPP, EPC, or concessional
Output produced
The blind spot this financing type predicts, and the record to demand first
Run this move →Example case
Move 2 · Test itfrom Day 2

Test it

Question
Can its value be judged at all?
Input needed
Are the terms published? And the NPV / value evidence, where it exists
Decision made
Assessable up front, only from outcomes, or not at all. Then check whether the funder, not publication, drives the pattern
Output produced
An assessability verdict. A withheld contract is a wall against assessment, and that is itself the finding
Run this move →Example case
Move 3 · Voice itfrom Day 3

Voice it

Question
Who needs standing to challenge the terms?
Input needed
Who is affected, and who holds the confidential terms
Decision made
Aim the publication ask at the funder and the contractor, not only the state
Output produced
A partner action note: the ask that gives the affected public standing to be heard
