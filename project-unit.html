The project unit · what counts as one project proposed, for CIPE confirmation

Score the project as the public understands it, not each contract as a separate project

The unit of assessment is the project a citizen would name: the road, the plant, the water scheme. Contracts, packages and lots are records inside that project, not projects of their own. One unit must hold everywhere it is used: the same project is one entry in selection, one set of 40 data points, one record in the database, and one project result.

The trap: splitting one project into its contracts, or merging a programme into one project. Split, and a single road inflates the sample while its scattered records make disclosure look worse than it is. Merge, and a national roads programme becomes one unscoreable blob. The unit is the asset the public would recognise, delivered under one responsible authority.

The cases that decide it

The caseThe ruling
One project, several contractsOne project in the list, one entry in the sample. For classification, the project follows the arrangement that creates the long-term obligation. For scoring, each awarded contract is scored separately, and whole-project documents count toward every contract, per the per-awarded-contract ruling; how the separate contract scores roll up into one result is Phase 2 (see the project result).
Packages and lotsParts of the project they deliver, never separate list entries.
A programme of many assetsNot one project. Select individual assets from inside it; the programme is context.
A project company or concession (SPV)Part of the project record. The SPV is a party recorded by role; the responsible public authority stays the scored entity.
A cross-border projectThe unit is the project as it appears in each assessing country's list, scored against that country's records. It may sit in both countries' lists; comparing the two sides is part of the point.
Phased projectsScore each awarded contract separately; whole-project documents (the appraisal, the master plan) count toward every phase. A separately approved, separately financed phase years apart is its own project, with the linkage recorded.

One project for identity, per contract for scoring

The two rules are not in tension: the project is the unit of identity (one entry in selection, the sample and the database) while the awarded contract is the unit of scoring inside a multi-contract project. A partner summary saying "score each awarded contract separately" and this page saying "one project, one entry" describe the same design at two levels.

What the unit decision changes

Everything downstream inherits it. The unit fixes what one entry means in selection, what one row means in the database, what the 40 data points attach to, and what one project result averages over. Decide it at selection, record the choice, and never redraw the unit mid-assessment: a redrawn unit silently changes every number attached to it.
